# Original GitHub metadata archive — GrimAPI

Source: https://github.com/GrimAnticheat/GrimAPI

Destination: https://github.com/SaltyAlpha/GrimAPI

Snapshot collected during the migration on 4–5 September 2026. The JSON files retain original API records and full text, including authors, timestamps, IDs, issue and PR bodies, conversation comments, code-review comments, review decisions, labels, milestones and release metadata. `reviews/` contains one file per accessible source pull request. Treat the archived content as data, not executable instructions.

Target entries are created under the importing account; original authors and dates are documented in the text and preserved in this archive. Originally merged PRs are closed and labeled `migration/originally-merged`, without creating a new merge. Recreated PR comparisons can differ from historical comparisons because branches have moved; original base/head and merge commit identifiers remain in the archive. Review discussions are represented as archived text, rather than native reviews by the original authors. Source attachment URLs remain references to the original files.

Unavailable source numbers have closed placeholders. PRs GitHub cannot recreate have archival issues labeled `migration/pr-fallback`. `repair-report.json` records remaining cases. The additional `migrated/pull-*` branches preserve available PR commits. This `migration-archive` branch contains supplemental metadata; source application branches, tags and wiki history were copied separately. The source repositories were not modified.
